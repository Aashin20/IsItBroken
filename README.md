# IsItBroken? 

**IsItBroken?** is an iOS application developed for the **Swift Student Challenge**. It serves as a preliminary medical triage tool designed to help users assess whether an ankle or foot injury requires a professional X-ray, utilizing the clinically-proven **Ottawa Ankle Rules**.

## 🚀 Overview

Ankle injuries are among the most common physical traumas, often leading to unnecessary emergency room visits and X-rays. This app provides a guided, step-by-step assessment to evaluate the necessity of medical imaging based on physical symptoms and mobility.

## ✨ Key Features

* **Guided Step Test:** A weight-bearing assessment that asks users to attempt four steps to check for functional stability.
* **Interactive 3D Palpation:** Uses a 3D anatomical model of the foot and ankle to help users identify and check for tenderness in specific "bony zones" (such as the posterior edge of the malleolus or the base of the fifth metatarsal).
* **Clinical Logic:** Implements the **Ottawa Ankle Rules**, a highly sensitive clinical decision tool used by healthcare professionals worldwide.
* **Clinic Locator:** If an X-ray is recommended, the app helps users instantly find nearby medical clinics via Apple Maps.
* **Instant Recommendations:** Provides a clear "X-Ray Recommended" or "X-Ray Not Likely Needed" result.
* **First Aid Guidance:** Includes integrated advice based on the **RICE protocol** (Rest, Ice, Compression, Elevation) for immediate injury management.
